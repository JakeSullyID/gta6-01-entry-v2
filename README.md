# Solmar Bay

Solmar Bay is an open-world crime game in the spirit of GTA 6 built with Three.js. Step into the shoes of Marco Solis, a professional driver-for-hire operating in a vibrant, sun-soaked coastal city where high-stakes jobs and police pursuits define everyday life.

## Controls
- **WASD / Arrows**: Move on foot or drive vehicles
- **E**: Enter or exit vehicle, or throw a punch
- **Shift**: Sprint on foot
- **Space**: Emergency handbrake while driving
- **Esc**: Pause simulation
- **M**: Toggle audio mute

## Missions
1. **First Fare**: Take your initial client across town before time expires.
2. **Borrowed Wheels**: Acquire a performance vehicle and evade the pursuing authorities.
3. **The Package**: Transport clandestine cargo through heavy city traffic.
4. **Midnight Run**: Complete the ultimate high-speed delivery under intense police pressure.

## Running Locally
1. Start the local static server:
   ```bash
   node serve.ts
   ```
2. Open your browser at:
   ```
   http://localhost:8080
   ```
